# Welcome to Zenith 

Zenith is an AI-powered study management application designed to help students learn more effectively using spaced repetition, productivity tools, and artificial intelligence. Students can add their complete syllabus and mark topics as completed. The application automatically schedules revisions after 1, 3, 5, 7, 15, and 30 days to improve long-term memory retention.

The dashboard provides daily revision reminders and a GitHub-style study heatmap that becomes darker as more study hours are completed. Zenith includes multiple built-in Pomodoro timers such as 50/10, 120/30, and 15/3, along with a custom timer and a stopwatch for flexible study tracking.

The AI Tutor offers Beginner, Moderate, Hard, and Quiz modes. Beginner teaches concepts from the fundamentals, Moderate provides standard explanations, Hard gives only hints to encourage critical thinking, and Quiz Mode tests understanding. A Rewards section motivates students through achievements, while the Friends section allows users to compete based on study time and consistency, making learning engaging and collaborative.
